# INNER LUMINA

A web piece of slow reflection: *Slow down. Reflect. Look around yourself.* Three zones (The Past, Connection, Legacy) hold ten questions each. They are set over a field of particles with an ambient drone, and an answer can be saved as a share image.

## Open it

https://sinaida-space.github.io/inner-lumina/

To run it locally, it is a Vite and React project: `npm install`, then `npm run dev`.
